# CommunityConnect

CommunityConnect is the GKMS community management portal for residents, board members, community managers and administrators.

## Current increment

Milestone 1 prepares a local, synthetic-data API prototype. S-1 (maintenance request submission and status retrieval) is the first implementation target. S-6 (simulated scheduled dues) is design/test-only. Real payments, production identity and deployment are outside this increment.

Initial feature-scoped work is being prepared through the AISE lifecycle. Setup, feature plans, tests and review evidence will arrive in a review branch before implementation is claimed complete.
